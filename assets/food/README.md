# Fotografii FridgeAlert

Imaginile WebP au fost generate pentru FridgeAlert cu OpenAI ImageGen. Aplicația le distribuie local și le poate afișa offline.

| Fișier | Subiect |
| --- | --- |
| `hero.webp` | Fructe și legume pentru Acasă |
| `omelette.webp` | Omletă cu brânză |
| `pasta.webp` | Paste cu roșii |
| `salad.webp` | Salată de legume |

Componenta `src/components/RecipePhoto.tsx` leagă fiecare fotografie de ID-ul rețetei. Pentru celelalte rețete afișează un simbol de preparat pe fundal verde-salvie. Pentru a completa catalogul, adaugă câte o fotografie proprie sau cu licență compatibilă pentru fiecare ID din listă, apoi actualizează maparea și notează sursa aici.
